# Third-party skills

These skills are copied unchanged from MIT-licensed Claude Code plugins, so everyone working on the
repository gets them without installing the plugins. To update them, copy the skill folders again
from a newer plugin version.

| Plugin | Version | Source | Skills |
| --- | --- | --- | --- |
| lattice | 2.1.0 | https://github.com/techygarg/lattice | architecture, clean-code, collaborative-judgment, context-anchoring, design-first, domain-driven-design, knowledge-priming, learning-harvest, refactor-safely, review, secure-coding, test-quality |
| audit-suite | 1.1.0 | https://github.com/Recusive/Orbit-plugin | audit-as-a11y-eng, audit-as-frontend-eng, audit-as-structural-eng, emil-design-engineering, vercel-react-best-practices, web-animation-design, web-design-guidelines |

The audit-suite lenses were written for another repository (Tauri app with `apps/`, `src-tauri/`, a
`reviews/` folder). Apply their checklists to this repository's layout instead.
